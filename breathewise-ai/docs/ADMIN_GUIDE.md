# Administrator & Moderator Guide

- **Community Moderators (`COMMUNITY_MODERATOR`):** Review flagged posts in the Moderation Queue and either keep the post or remove harmful/misleading content (all moderation actions are audit-logged).
- **System Administrators (`SYSTEM_ADMIN`):** Monitor API/AI latency and fallback counts, manage user roles, publish verified educational resources, and inspect security audit logs.
- **Privacy Boundary:** Administrators cannot view individual users' private AI conversation histories.
